# H.C.C BRAND SYSTEM

Derived from the delivered campaign creative and the in-game console aesthetic. Use this for every future marketing asset so the library stays coherent.

## Name and lockup

- Written as **H.C.C** in headlines and CTAs, **H.C.C.** in prose.
- Eyebrow lockup, letter-spaced, uppercase: `H.C.C — HUNTING CYBER CRIMINALS`
- Always at the top of a poster, muted slate-cyan, never larger than the headline.

## Frame

- Deep near-black canvas with a faint square technical grid.
- Thin L-shaped corner brackets at all four corners, inset from the edge — the signature framing device. Do not omit.

## Colour roles

| Role | Use | Approx. |
| --- | --- | --- |
| Canvas | Background | `#04070A` near-black |
| Grid | Background structure | very low-opacity slate |
| Signal cyan | Headlines, CTA, active state, glow | `#5FD8F5` |
| Confirm green | Evidence filed, identity confirmed, completed chips | `#3BE08A` |
| Threat red | Open cases, critical threat, live trace | `#FF3B54` |
| Rank amber | Top rank / aspiration highlight | `#FFC24A` |
| Muted slate | Labels, metadata, disclaimer | `#7C8B99` |
| Pure white | Setup line of a two-part headline | `#FFFFFF` |

Rule: one accent dominates per asset. Reveal = green payoff, Climb = amber peak on cyan ladder, Open Case = red.

## Typography

- Headlines: condensed geometric sans, uppercase, tight, with a soft cyan glow on the payoff line.
- Everything else — labels, logs, metadata, disclaimer: monospace, letter-spaced, uppercase for labels, sentence case for log lines.
- Never mix in a third typeface. No serifs.

## Layout

- Vertical: eyebrow → headline → panel(s) → status line → CTA button → disclaimer.
- Panels are 1px-bordered rectangles tinted by the asset's accent colour.
- Generous vertical breathing room; large empty regions are intentional.
- CTA is a full-width outlined button, never a filled blob, always reading `PLAY H.C.C FREE`.

## Motion

- Terminal behaviour only: type-on text, scanline sweeps, chip state flips, stamp impacts, brief glitch on cuts.
- No confetti, no glassmorphism, no neon gradients, no bouncing easing. Soft, restrained, fast.

## Voice

Warm, quiet, literary, brief, honest. Second person. Short declaratives. No emojis, no exclamation marks, no hype, no fake scarcity.

## Mandatory elements on every public asset

1. The `H.C.C — HUNTING CYBER CRIMINALS` eyebrow.
2. The CTA `PLAY H.C.C FREE`.
3. The disclaimer: *Fiction. Targets, operators and payloads are invented.*

## Never

- Never imply real hacking, real doxxing, or real people as targets.
- Never show a real IP, handle, wallet address or company. Use reserved documentation ranges.
- Never promise earnings, payouts, or real-money returns from mining or Stars.
